# Configuración

## Crear usuario administrador

- Usuario
- Contraseña

---

## Seleccionar entorno

Elegir:

```.
Local
```

---

## Verificar conexión

En el Dashboard debe aparecer:

- Docker Version
- Containers
- Images
- Networks
- Volumes

---

## Configuración recomendada

- Habilitar HTTPS (9443).
- Deshabilitar el puerto 9000 (obsoleto).
- Utilizar volúmenes persistentes.
